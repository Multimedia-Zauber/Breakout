# Neon Breakout

Retro Arcade Game #06

## Features

- klassisches Breakout-Prinzip
- mehrere Blockreihen
- mehrere Levels
- steigende Ballgeschwindigkeit
- Score
- Highscore via localStorage
- 3 Leben
- Power-ups:
  - W = breiter Schläger
  - + = Extra-Leben
  - S = Slow Motion
- stärkere Blöcke in höheren Levels
- Touch-Steuerung
- Pause
- Neon-Retro-Look

## Steuerung

- Pfeil links / A = links
- Pfeil rechts / D = rechts
- Leertaste = Ball starten
- P = Pause
